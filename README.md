# Хроники магической Британии

Веб-приложение для проработки материалов любительской художественной литературы: таймлайн, интерактивная карта, персонажи, связи между записями, пробковая доска и галерея. Это демо-версия с данными из вселенной Поттерианы. 

Демо: https://Benitoi1.github.io/demo-roleplay-site/

Проект не связан с правообладателями Поттерианы. Описания персонажей и событий написаны своими словами и нужны только для демонстрации возможностей приложения.

## Возможности

- Два мира с отдельными темами оформления и записями: мир маглов и мир магов
- Таймлайн с глобальным и локальным сюжетом и перетаскиванием событий
- Карта с масштабированием, перетаскиванием, добавлением точек долгим нажатием
- Персонажи с графом отношений (SVG), типы связей с цветами
- Пробковая доска: исследование записей по связям, нити, перетаскивание листочков, сохранение в браузере
- Ссылки на записи в тексте в виде `[[слово|таблица:id]]`, нечёткий поиск, обратные ссылки «Упоминается в»
- Редактирование с блокировкой записи на время правки другим пользователем
- Загрузка картинок со сжатием в WebP, галерея, избранное
- Адаптивный интерфейс, PWA, поддержка prefers-reduced-motion

## Технологии

- JavaScript (ES-модули), без фреймворков и сборки
- Supabase: PostgreSQL, Auth, Storage, политики Row Level Security
- GitHub Pages, GitHub Actions (периодический запрос, чтобы бесплатная база не засыпала)

## Устройство

```
js/
  app.js          состояние, вкладки, карточка записи
  store.js        кэш данных и доступ к таблицам
  models.js       классы записей и запросы с повтором при сбоях сети
  tabs/           вкладки подключаются как независимые модули
  render.js       отрисовка списков, таймлайна, карточки, лайтбокса
  map.js          карта: масштаб, жесты, контекстное меню
  board.js        пробковая доска и нити
  relations.js    граф отношений и форма связей
  editor.js       редактор текста с форматированием и вставкой ссылок
  richtext.js     разбор разметки в DOM без innerHTML
  forms.js        описания форм для каждой таблицы
  locks.js        блокировки редактирования с heartbeat
  upload.js       сжатие и загрузка изображений

```

Права на запись есть только у вошедшего пользователя, посетители могут только читать. Регистрация в проекте Supabase отключена.
