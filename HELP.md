# Как пользоваться сайтом

Это демо-версия сайта для проработки материалов любительской художественной литературы. Здесь собраны события, карта, персонажи, картинки и другие записи из Поттерианы. Все данные используются только для демонстрации. Без входа сайт открыт только для чтения.

## Два мира

Переключатель «Мир маглов / Мир магов» меняет оформление и показывает записи выбранного мира. Выбор запоминается. На карте переключателя нет: карта одна.

## Вкладки

- **Таймлайн**: события по порядку. Сверху можно переключать глобальный и локальный сюжет
- **Карта**: поселения на карте Британии
- **Доска**: пробковая доска, на которой можно исследовать записи по их связям
- **Персонажи**: все персонажи выбранного мира по алфавиту
- **Галерея**: все картинки. В неё попадают и те, что прикреплены к записям, с подписью «из записи ...»
- **Другое**: поселения, события и все остальные записи. Можно фильтровать по типу

В большинстве вкладок есть строка поиска, он ищет по названиям и описаниям.

## Таймлайн

Клик по событию открывает карточку. После входа событие можно перетащить: на компьютере зажать мышкой, на телефоне задержать палец примерно на полсекунды.

## Карта

Приближать можно колесом мыши, кнопками + и − или двумя пальцами. Двигать карту можно перетаскиванием, кнопка со стрелкой возвращает вид по умолчанию. Клик по точке или по названию в списке под картой открывает карточку поселения.

После входа новое поселение добавляется так: на компьютере правая кнопка мыши по месту на карте, на телефоне долгое нажатие. Нужно выбрать «+ Добавить поселение», координаты подставятся сами.

## Доска

На доске можно разобраться, как связаны записи. Нажмите на свободное место пустой доски, и там появится пустой листочек с кнопкой «Исследовать». В открывшемся списке выберите одну запись (есть поиск и галочка «Показывать записи из другого мира»). Вокруг неё появятся листочки со связанными записями, а между ними протянутся нити.

- Клик по листочку открывает запись. На листочке видны название, тип и начало описания
- Долгое нажатие на листочке (на компьютере правая кнопка мыши) открывает меню. «Исследовать» добавляет записи, связанные с этой, «Убрать» убирает листочек с доски (сама запись не удаляется)
- Долгое нажатие по свободному месту на построенной доске открывает «Сбросить доску». Сбрасывается только доска, записи остаются
- Кнопки + и − в правом верхнем углу доски меняют масштаб, стрелка возвращает масштаб по умолчанию. На компьютере масштаб меняется ещё через Ctrl и колесо мыши
- У каждого мира своя доска. Она хранится в браузере на этом устройстве

## Карточка записи

Карточка открывается сбоку, а на телефоне снизу. На компьютере её ширину можно менять, потянув за левый край (двойной клик сбрасывает).

- Картинки открываются крупно, между ними можно листать стрелками или свайпом
- «Связано» показывает записи, которые выбраны в этой записи
- «Упоминается в» показывает записи, которые ссылаются на эту
- «Назад» возвращает к предыдущей карточке
- У персонажей есть вкладка «Отношения» с графом: наведите мышь на линию, и появится подпись с типом связи и направлением. Стрелка идёт от того, кто в этой роли, к тому, для кого

## Редактирование

Редактирование доступно только владельцу сайта после входа: кнопка «+ Добавить», перо, корзина и избранное. Картинки сжимаются автоматически, файл не больше 15 МБ. Текст описаний поддерживает оформление (жирный, курсив, заголовок, список, цитата) и ссылки на другие записи в виде `[[слово|characters:12]]`. Пока запись редактирует один человек, другим она недоступна для правки.
